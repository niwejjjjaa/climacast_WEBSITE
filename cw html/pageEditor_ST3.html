Feedback page

Technical Description

The navigation bar with the necessary links and the profile-icon are implemented inside a header using a header tag. Nav and ul tags were used to access the menu.labels and input tags were used to improve the usability with the fields. using the fieldset and form tags the feedback form has been grouped accorinding to its similarities and for better structure. As for the interactive elements a rating system has been added usig span stars and a data-value attribute to get the user ratings. Also radio buttons were added allowing user to input "YES" or "NO" answers regarding the usability of the webiste.

In the css styling part a flexbox was added to do the layout management in the header and form sections. @media queries will adjust the layout screen sizes.For styling theres border-radius tags, background color changes and paddings used to ensure user freindliness. Hover effects and transitions were also used and they will enhance user intercations by changing colors and scaling elements. the rating system has (.star.selected { color: gold; }) tags to highlight the selection of stars by the user.

As mentioned in the above , this content of the page also got the header, navigation bar and the footer which also contains social media icons and credits, with hover effects to highlight them .In the main content its got details about each team member inside the team container with each members photo and details of the contribution of theirs. the contribution and the details will appear once the user hovers on the photo of related member.

Content Page

Technical Description

As same as in the other pages there is the header tag containing the website logo, navigation links and profile icon. using the nav tag navigation bar is grouped and it makes it easier to navigate through the page. Using the (Div class="container") tag there is containers sectioned and each container has and image and an alt text describing picture along with the tips regarding the containers heading. The footer tag is also there and as same as in the above pages it has got the contributors name alongside the social media icons.

In order to make the page more interactive to the user; hover effects are implemented in each container while changing the color and the size when hoverd. In the content layout there is a flexbox used and it will arrange the images and texts properly in every container card. The cards layout of odd and even card numbers are alternated so the images and the contet swap the text alignment in the layout.

Accessibility

All images have alt attributes so the screen readers could know what that image is. The background colors were also changed boosting the contrast of the texts ensureing the readability for the users. Adding media queries ensure the lay out is working properly regardless of the device by adjusting the content layout and navigation layout.
